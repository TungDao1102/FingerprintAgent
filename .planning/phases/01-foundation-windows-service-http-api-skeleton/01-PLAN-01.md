# Plan 01: Walking Skeleton Core — Project Scaffold + HTTP Listener + Mock Capture

**User story:** As a developer, I want to build and run the agent as a console app so that I can verify `GET /health` and `POST /api/capture` return correct responses with mock data.

**Goal:** Deliver the thinnest end-to-end slice: .NET Framework 4.8 executable that binds `127.0.0.1:5043` and responds to both endpoints with hardcoded values (no config, no CORS, no service mode, no logging yet).

```xml

    `Router.cs` for URL-to-handler dispatch, and `Program.cs` with dual-mode
    (console / service) entry point.

    No CORS middleware yet (Plan 02). No config loading yet (Plan 02) — hardcode
    host `127.0.0.1` and port `5043` for now. No structured logging yet (Plan 04)

    Request body validation: check that `thamChieuId` is non-empty, `maPhieu` is non-empty.
    Return HTTP 400 with `INVALID_REQUEST` errorCode for missing fields.
    Return HTTP 404 for unknown routes.
  </description>
  <read_first>
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-RESEARCH.md (§2.1 HttpListener, §2.10 Test Commands, §5.1 Walking Skeleton, §5.2 Program.cs, §5.5 Request Body Parsing, §5.6 Response DTO, §5.7 Request Dispatch)

    - `Invoke-RestMethod -Uri http://localhost:5043/health -Method Get` returns JSON with fields: `status` (string), `deviceId` (string), `uptime` (string)
    - `Invoke-RestMethod -Uri http://localhost:5043/api/capture -Method Post -Body '{"thamChieuId":"t1","maPhieu":"P1"}' -ContentType "application/json"` returns JSON with: `isSuccess` = true, `imageBytes` (non-empty base64), `verificationData` (44-char base64), `mimeType` = "image/png", `deviceId` = "mock-scanner-001", `capturedAt` (ISO 8601)
    - `Invoke-RestMethod -Uri http://localhost:5043/api/capture -Method Post -Body '{}' -ContentType "application/json"` throws HTTP 400
    - `Invoke-WebRequest -Uri http://localhost:5043/nonexistent -Method Get` returns HTTP 404
    - `netstat -an | findstr 5043` shows `127.0.0.1:5043` in LISTEN state
    - After Ctrl+C, `netstat -an | findstr 5043` shows port released (no LISTEN)
  </acceptance_criteria>
  <action>
    - Create `src/FingerprintAgent/Models/CaptureRequest.cs` — class with `[JsonProperty("thamChieuId")] string ThamChieuId`, `[JsonProperty("maPhieu")] string MaPhieu`, `[JsonProperty("loaiPhieu")] string LoaiPhieu`, `[JsonProperty("vaiKyId")] string VaiKyId`, `[JsonProperty("nhanLucId")] string NhanLucId`, `[JsonProperty("metadata")] Dictionary<string, string> Metadata`.
    - Create `src/FingerprintAgent/Models/CaptureResponse.cs` — class with `[JsonProperty("isSuccess")] bool IsSuccess`, `[JsonProperty("imageBytes")] string ImageBytes`, `[JsonProperty("mimeType")] string MimeType`, `[JsonProperty("capturedAt")] string CapturedAt`, `[JsonProperty("deviceId")] string DeviceId`, `[JsonProperty("verificationData")] string VerificationData`, `[JsonProperty("errorMessage")] string ErrorMessage`.
    - Create `src/FingerprintAgent/Api/HttpServer.cs` — class wrapping `HttpListener`. Constructor takes `host` (string), `port` (int), `IScannerAdapter`. Method `Start()`: create listener, add prefix `http://{host}:{port}/`, `listener.Start()`, dispatch `Task.Factory.StartNew(() => ProcessRequestLoop(cancellationToken), TaskCreationOptions.LongRunning)`. Method `Stop()`: `listener.Stop()`, `listener.Close()`. The `ProcessRequestLoop` calls `GetContextAsync()` in a loop, dispatches each to `Task.Run(() => HandleRequest(context))`, catches `ObjectDisposedException`/`HttpListenerException` as stop signal. `HandleRequest` reads URL path + method, routes to appropriate handler, writes JSON response. Set `ContentType = "application/json"` on every response.
    - Create `src/FingerprintAgent/Api/HealthHandler.cs` — static class (or instance method) `Handle(HttpListenerContext context, IScannerAdapter scanner)`: build anonymous JSON object `{status: "healthy", deviceId: scanner.DeviceId, uptime: (DateTime.UtcNow - _startTime).ToString(@"hh\:mm\:ss")}`, serialize with `JsonConvert.SerializeObject`, write to response output stream. HTTP 200.
    - Create `src/FingerprintAgent/Api/CaptureHandler.cs` — class `Handle(HttpListenerContext context, IScannerAdapter scanner)`: read request body stream → string via `StreamReader`. Validate non-empty body → HTTP 400 `{"isSuccess":false,"errorMessage":"Request body is empty","errorCode":"INVALID_REQUEST"}`. Deserialize with `JsonConvert.DeserializeObject<CaptureRequest>(body)`. Validate `ThamChieuId` and `MaPhieu` are non-null → HTTP 400 with appropriate errorMessage. Call `scanner.Scan()`. Build `CaptureResponse` with `IsSuccess=true`, `ImageBytes=Convert.ToBase64String(result.ImageBytes)`, `MimeType="image/png"`, `CapturedAt=DateTime.UtcNow.ToString("O")`, `DeviceId=scanner.DeviceId`, `VerificationData=result.VerificationData`. Serialize with `JsonConvert.SerializeObject`. Write to response. Handle exceptions from `scanner.Scan()` → HTTP 500 `CAPTURE_FAILED`.
    - Create `src/FingerprintAgent/Program.cs` — class `Program`. `Main(string[] args)`: check `Environment.UserInteractive || args.Contains("--console")`. If console: instantiate `MockScannerAdapter`, instantiate `HttpServer("127.0.0.1", 5043, scanner)`, call `server.Start()`, attach `Console.CancelKeyPress` to call `server.Stop()`, `Console.ReadLine()`, `server.Stop()`. If service: `ServiceBase.Run(new FingerprintAgentService())` (note: `FingerprintAgentService` created in Plan 03 — for now, console mode is the only working path).
    - Create `tests/FingerprintAgent.Tests/HttpServerIntegrationTests.cs` with [Fact] tests that start the `HttpServer` in-process, send HTTP requests via `HttpClient`, and verify responses. Tests: `HealthEndpoint_Returns200`, `CaptureEndpoint_WithValidBody_Returns200_AndImageBytes`, `CaptureEndpoint_WithEmptyBody_Returns400`, `CaptureEndpoint_WithMalformedJson_Returns400`, `UnknownEndpoint_Returns404`.
```
