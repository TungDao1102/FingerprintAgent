# Plan 03: Windows Service Hosting + PowerShell Scripts

**User story:** As an IT administrator, I want to install the agent as a Windows Service with `Install-Service.ps1` so that it starts automatically on boot and runs reliably in the background.

**Goal:** Create `FingerprintAgentService` as a `ServiceBase` subclass with `OnStart`/`OnStop` lifecycle. Wire it into `Program.cs` dual-mode (`--service` flag for SCM, `--console` for debugging). Create `Install-Service.ps1`, `Uninstall-Service.ps1`, and `Test-Capture.ps1` for service lifecycle management.

## Task 01-03-01: FingerprintAgentService — ServiceBase Subclass

```xml
<task id="01-03-01" type="execute">
  <description>
    Create `FingerprintAgentService` extending `ServiceBase`. Implement `OnStart(string[] args)`
    to load config, initialize the mock scanner, create and start `HttpServer` on a background
    thread (must return within 30 seconds). Implement `OnStop()` to cancel the cancellation token,
    stop the HTTP listener, and flush logs.

    Update `Program.cs` to support `--service` mode: when launched by SCM (no `--console` flag
    and not `Environment.UserInteractive`), call `ServiceBase.Run(new FingerprintAgentService())`.
    When launched with `--service` (for sc.exe), also call `ServiceBase.Run`.

    Ensure `HttpServer.Stop()` properly unblocks the `GetContextAsync()` loop by calling
    `HttpListener.Stop()` first (which throws `ObjectDisposedException`).
  </description>
  <read_first>
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-RESEARCH.md (§2.2 ServiceBase Lifecycle, §2.3 PowerShell scripts, §3.2 OnStart Timeout, §3.6 HttpListener.GetContext Blocks)
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-PATTERNS.md (items 3, 4)
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-CONTEXT.md (D-06)
    - .planning/REQUIREMENTS.md (SVC-01, SVC-02, SVC-03, SVC-05)
    - Current `src/FingerprintAgent/Program.cs` (to add service mode branching)
    - Current `src/FingerprintAgent/Api/HttpServer.cs` (may need `Stop()` / cancellation improvements)
  </read_first>
  <acceptance_criteria>
    - Class `FingerprintAgentService` extends `System.ServiceProcess.ServiceBase`
    - `OnStart()` returns within 5 seconds (verified via `Start-Service` → `Get-Service` shows Running)
    - After `OnStart()`, `GET /health` responds successfully on configured port
    - After `OnStop()`, port 5043 is released (verified via `netstat -an | findstr 5043`)
    - `Program.cs` dispatches to `ServiceBase.Run()` when launched without `--console` and not user-interactive
    - `Program.cs` also dispatches to `ServiceBase.Run()` when `--service` flag is present
    - Build succeeds with `System.ServiceProcess` reference (in-box in .NET Framework)
  </acceptance_criteria>
  <action>
    - Ensure `FingerprintAgent.csproj` includes `<Reference Include="System.ServiceProcess" />` (required for `ServiceBase`). This is an in-box assembly for .NET Framework, not a NuGet package.
    - Create directory `src/FingerprintAgent/Service/`.
    - Create `src/FingerprintAgent/Service/FingerprintAgentService.cs`:
      - Class inherits `ServiceBase`. Set `ServiceName = "FingerprintAgent"`, `AutoLog = true` (for basic SCM logging).
      - Fields: `private HttpServer _httpServer`, `private IScannerAdapter _scanner`, `private AgentConfig _config`, `private CancellationTokenSource _cts`.
      - `OnStart(string[] args)`:
        1. Call `ConfigLoader.Load()` to get `AgentConfig` (wrap in try-catch, write to EventLog on failure, throw to prevent service start).
        2. Create `MockScannerAdapter()`.
        3. Create `CorsMiddleware(config.Cors.Mode, config.Cors.AllowedOrigins)`.
        4. Create `HttpServer(config.Http.Host, config.Http.Port, scanner, cors, config)`.
        5. Call `_httpServer.Start()` (this starts the background listener loop — non-blocking).
        6. Log "Service started successfully" to EventLog via `EventLog.WriteEntry("FingerprintAgent", "Service started", EventLogEntryType.Information)`.
      - `OnStop()`:
        1. `_cts?.Cancel()`
        2. `_httpServer?.Stop()` (this calls `HttpListener.Stop()` which unblocks `GetContextAsync()`)
        3. Log "Service stopped" to EventLog.
      - Add `public void Start()` method (for console mode) that calls `OnStart(null)`.
      - Add `public new void Stop()` method (for console mode) that calls `OnStop()`.
    - Modify `src/FingerprintAgent/Program.cs`:
      - In `Main()`: if `args.Contains("--service")` or `!Environment.UserInteractive`: use `ServiceBase.Run(new FingerprintAgentService())`.
      - If `args.Contains("--console")` or `Environment.UserInteractive`: use the existing console mode path but instantiate `FingerprintAgentService` and call `service.Start()` / `service.Stop()` (reuse the same lifecycle, just without SCM).
      - Console mode: attach `Console.CancelKeyPress` to call `service.Stop()`. Print "Service running. Press Ctrl+C to stop." then `Console.ReadLine()`.
    - Ensure `HttpServer.cs` (from Plan 01) has a proper `Stop()` method that sets the cancellation token, calls `_listener.Stop()`, and waits briefly for the request loop to exit.
  </action>
</task>
```

## Task 01-03-02: PowerShell Scripts — Install, Uninstall, Test

```xml
<task id="01-03-02" type="execute">
  <description>
    Create three PowerShell scripts in the `scripts/` directory:
    `Install-Service.ps1` (elevated, creates service + EventLog source + log directory),
    `Uninstall-Service.ps1` (elevated, stops and removes service),
    `Test-Capture.ps1` (non-elevated, smoke-tests both endpoints).

    Scripts use the patterns from RESEARCH.md §2.3.
  </description>
  <read_first>
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-RESEARCH.md (§2.3 Installing/Uninstalling Service, §2.3 PowerShell scripts, §2.9 EventLog Source, §2.10 Test/Verification Commands)
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-PATTERNS.md (items 21, 22, 23)
    - .planning/phases/01-foundation-windows-service-http-api-skeleton/01-RESEARCH.md (§3.4 EventLog source creation, §3.9 Service not starting, §3.7 Port conflict)
    - .planning/REQUIREMENTS.md (SVC-01, SVC-02, SVC-05)
  </read_first>
  <acceptance_criteria>
    - `.\scripts\Install-Service.ps1` (elevated) creates service `FingerprintAgent` with `StartType Automatic`
    - `Get-Service FingerprintAgent` returns service with `Status Stopped` after install
    - `Start-Service FingerprintAgent` → `Get-Service FingerprintAgent` shows `Status Running`
    - After start, `Invoke-RestMethod http://localhost:5043/health` returns 200
    - `Get-EventLog -LogName Application -Source FingerprintAgent -Newest 3` returns at least "Service started" entry
    - `C:\ProgramData\FingerprintAgent\Logs\` directory exists
    - `.\scripts\Uninstall-Service.ps1` (elevated) removes service successfully
    - `Get-Service FingerprintAgent -ErrorAction SilentlyContinue` returns null after uninstall
    - `.\scripts\Test-Capture.ps1` (any user) calls `/health` and `/api/capture` and prints JSON results
    - All scripts are idempotent (Install works if service already exists, Uninstall handles missing service)
  </acceptance_criteria>
  <action>
    - Create directory `scripts/` if not exists.
    - Create `scripts/Install-Service.ps1`:
      - Parameters: `-BinPath` (default: `"$PSScriptRoot\..\src\FingerprintAgent\bin\Release\net48\FingerprintAgent.exe"`), `-LogDir` (default: `"C:\ProgramData\FingerprintAgent\Logs"`).
      - Check if running as administrator (`[Security.Principal.WindowsPrincipal]::new([Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)`). If not admin, print error and exit 1.
      - Verify `$BinPath` exists. If not, print error and exit 1.
      - If service already exists: `Stop-Service $serviceName -Force -ErrorAction SilentlyContinue`; `sc.exe delete $serviceName`; `Start-Sleep -Seconds 2`.
      - `New-Service -Name "FingerprintAgent" -BinaryPathName "$BinPath --service" -DisplayName "Fingerprint Agent" -Description "Local fingerprint capture service providing HTTP API for web applications" -StartupType Automatic`.
      - `sc.exe failure FingerprintAgent reset=86400 actions=restart/5000/restart/10000/restart/30000` (recovery: restart after 5s, 10s, 30s).
      - Create log directory if not exists: `New-Item -ItemType Directory -Path $LogDir -Force`.
      - Register EventLog source: `if (-not [System.Diagnostics.EventLog]::SourceExists("FingerprintAgent")) { [System.Diagnostics.EventLog]::CreateEventSource("FingerprintAgent", "Application") }`.
      - Print success message.
    - Create `scripts/Uninstall-Service.ps1`:
      - Parameters: `-ServiceName` (default: `"FingerprintAgent"`).
      - Check admin. If service exists: `Stop-Service $ServiceName -Force -ErrorAction SilentlyContinue`; `sc.exe delete $ServiceName`; print "Service $ServiceName removed." Else: print "Service $ServiceName not found."
    - Create `scripts/Test-Capture.ps1`:
      - Parameters: `-BaseUrl` (default: `"http://localhost:5043"`), `-ThamChieuId` (default: `"test-001"`), `-MaPhieu` (default: `"P2026-0001"`), `-SaveImage` (switch).
      - Step 1: `$health = Invoke-RestMethod -Uri "$BaseUrl/health" -Method Get`; print health JSON.
      - Step 2: Build request body with `thamChieuId`, `maPhieu`, `loaiPhieu`, `vaiKyId`, `nhanLucId`, `metadata` (with `source: "Test-Capture.ps1"`).
      - Step 3: `$capture = Invoke-RestMethod -Uri "$BaseUrl/api/capture" -Method Post -Body $body -ContentType "application/json"`.
      - Print: `isSuccess`, `deviceId`, `verificationData`, `capturedAt`.
      - If `-SaveImage`: decode base64 `$capture.imageBytes` and save to `$env:TEMP\fingerprint-capture.png`. Print file path.
      - If error: print error details.
  </action>
</task>
```
