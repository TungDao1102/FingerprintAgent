  <read_first>
    src/FingerprintAgent/Adapters/MockScannerAdapter.cs
  </read_first>
  <action>
    Create new file src/FingerprintAgent/Adapters/BaseScannerAdapter.cs as abstract base class:

    1. Abstract properties: DeviceId, Model, VendorErrorCode — subclasses implement these.

    2. Abstract method: `bool InitializeDevice()` — called by Initialize() for vendor-specific device open logic.

    3. Abstract method: `byte[] CaptureRawImage()` — returns raw grayscale bytes from vendor SDK (width*height buffer). Subclasses handle SDK capture and any format conversion.

    4. Non-virtual method `CaptureResult Scan()`: calls InitializeDevice(), then CaptureRawImage(), then converts raw bytes to PNG via ToPngGrayscale(). Returns success CaptureResult or failure with error message.

    5. Protected helper `byte[] ToPngGrayscale(byte[] raw, int width, int height)`: creates an 8bpp indexed Bitmap with grayscale palette, copies raw bytes via Marshal.Copy, saves to MemoryStream as PNG. Disposes GDI+ objects per-call pattern (matching MockScannerAdapter). Returns PNG byte[].

    6. Protected field `_lastError` for subclasses to store VendorErrorCode string.

    This base class is NOT mandatory for adapter implementations but reduces duplication across SecuGenAdapter, DigitalPersonaAdapter, and FutronicAdapter (Plans 02-01, 02-02). Subclasses may override Scan() entirely if needed.
  </action>

  </verify>
  <done>BaseScannerAdapter exists with abstract DeviceId/Model/VendorErrorCode properties, abstract InitializeDevice/CaptureRawImage methods, and non-virtual Scan() that calls InitializeDevice → CaptureRawImage → ToPngGrayscale.</done>
