  <behavior>

    - Scan() iterates adapters: initialize → scan → return on success; on failure try next
    - 10-second CancellationTokenSource.CancelAfter covers all adapter attempts combined
    - Per-adapter timeout: ~3 seconds (connect + capture) via linked CancellationTokenSource
    - On timeout: return CaptureResult with ErrorMessage="CAPTURE_TIMEOUT"
    - On all fail: return CaptureResult with ErrorMessage="SCANNER_NOT_CONNECTED"
    - IsConnected/DeviceId/Model delegate to _activeAdapter after successful scan
    - MockMode=true bypasses all real adapters and uses MockScannerAdapter directly
    - SCAN-06 (review finding): if active adapter's IsConnected=false on next call, retry same adapter once before full fallback — implements backoff reconnection pattern
    - Config validation (review finding): unknown vendor name in Priority array throws exception — fail-fast on misconfiguration, not silent reduction
  </behavior>
  <action>
    Create src/FingerprintAgent/Adapters/ScannerManager.cs implementing IScannerAdapter:

    1. Class fields: IScannerAdapter[] _adapters (in priority order); IScannerAdapter _activeAdapter; AgentLogger _logger; ScannerConfig _config; CancellationTokenSource _cts; string _lastVendorErrorCode; bool _mockMode; IScannerAdapter _lastActiveAdapter.

    2. Constructor: ScannerManager(AgentConfig config, AgentLogger logger). If config.Scanner.MockMode == true: _mockAdapter = new MockScannerAdapter(); _mockMode = true; return. Else: build _adapters list from config.Scanner.Priority array by instantiating per vendor name: "SecuGen" → new SecuGenAdapter(), "DigitalPersona" → new DigitalPersonaAdapter(), "Futronic" → new FutronicAdapter(). Log each adapter instantiation at INFO level. **REVIEW FIX (unknown vendor):** If vendor name not recognized, throw InvalidOperationException with message "Unknown scanner vendor in config.Scanner.Priority: '{name}'. Valid names: SecuGen, DigitalPersona, Futronic, ZKTeco" — fail-fast on config typo, do not silently skip.

    3. IScannerAdapter properties: IsConnected (get { return _mockMode ? _mockAdapter.IsConnected : (_activeAdapter?.IsConnected ?? false); }), DeviceId (get { return _mockMode ? _mockAdapter.DeviceId : (_activeAdapter?.DeviceId ?? "no-device"); }), Model (get { return _mockMode ? _mockAdapter.Model : (_activeAdapter?.Model ?? "no-device"); }), MimeType ("image/png"), VendorErrorCode (get { return _mockMode ? "MOCK" : (_activeAdapter?.VendorErrorCode ?? "NO_ADAPTER"); }).

    4. Scan() method: if (_mockMode) return _mockAdapter.Scan(). Create linked CancellationTokenSource: var totalCts = CancellationTokenSource.CreateLinkedTokenSource(_cts.Token); totalCts.CancelAfter(TimeSpan.FromSeconds(10)); // D-06 total budget. **SCAN-06 backoff:** If _activeAdapter != null and !_activeAdapter.IsConnected, log "ScannerManager: active adapter disconnected, retrying once" and attempt _activeAdapter.Initialize() once before the priority list loop. If that retry succeeds, proceed with _activeAdapter.Scan(). If it fails, fall through to normal priority fallback. foreach (var adapter in _adapters) { if (totalCts.Token.IsCancellationRequested) { _logger?.Warning("ScannerManager: total timeout exceeded"); return new CaptureResult { IsSuccess = false, ErrorMessage = "CAPTURE_TIMEOUT" }; } var adapterCts = CancellationTokenSource.CreateLinkedTokenSource(totalCts.Token); adapterCts.CancelAfter(TimeSpan.FromSeconds(3)); // D-06 per-adapter budget. try { _logger?.Debug($"Trying adapter {adapter.GetType().Name}"); if (adapter.Initialize()) { var result = adapter.Scan(); if (result.IsSuccess) { _activeAdapter = adapter; _logger?.Info($"ScannerManager: {adapter.GetType().Name} succeeded, DeviceId={adapter.DeviceId}"); return result; } else { _logger?.Warning($"ScannerManager: {adapter.GetType().Name} scan failed: {result.ErrorMessage}"); } } else { _logger?.Warning($"ScannerManager: {adapter.GetType().Name} initialize returned false: {adapter.VendorErrorCode}"); } } catch (Exception ex) { _logger?.Error($"ScannerManager: {adapter.GetType().Name} threw {ex.GetType().Name}: {ex.Message}"); } } _logger?.Error("ScannerManager: all adapters failed"); return new CaptureResult { IsSuccess = false, ErrorMessage = "SCANNER_NOT_CONNECTED" }.

    5. If _activeAdapter is set after a successful scan, all property getters delegate to it for HealthHandler.

    **D-01 Design Clarification (per review finding):** Per-call Initialize() is intentional — D-01 specifies "no persistent connection state between requests." Each Scan() call starts fresh, which is correct for lazy-connect semantics. If an adapter's device is already open from a prior call, the vendor SDK must handle this idempotently (e.g., SecuGen returns ERROR_DEV_ALREADY_OPEN, which maps to a retryable condition). The backoff retry in this task addresses temporary disconnections specifically.
