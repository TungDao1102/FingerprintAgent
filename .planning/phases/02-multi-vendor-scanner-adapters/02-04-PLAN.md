  <action>
    Create src/FingerprintAgent/Adapters/ZKTecoAdapter.cs implementing IScannerAdapter:

    1. Add using statements: `System`, `System.Drawing`, `System.Drawing.Imaging`, `System.IO`, `System.Security.Cryptography`, `System.Threading`, `System.Threading.Tasks`, `ZkTecoFingerPrint`.

    2. Class fields:
       - `ZkTecoFingerHost? _zkHost` (lazy init in Initialize)
       - `ZkDevice? _device` (opened device, IDisposable)
       - `int _width`, `int _height`
       - `string _deviceId` (default "ZKTeco-unknown"), `string _model` (default "ZKTeco Device"), `string _vendorErrorCode` (default "NONE")
       - `bool _isConnected`
       - `static readonly string[] _zkErrorStrings` mapping ZKFP_ERR codes: 0→"ERROR_NONE", -1→"ERROR_INITLIB", -2→"ERROR_INIT", -3→"ERROR_NO_DEVICE", -4→"ERROR_NOT_SUPPORT", -5→"ERROR_INVALID_PARAM", -6→"ERROR_OPEN", -7→"ERROR_INVALID_HANDLE", -8→"ERROR_CAPTURE", -9→"ERROR_EXTRACT_FP", -10→"ERROR_ABORT", -11→"ERROR_MEMORY_NOT_ENOUGH", -12→"ERROR_BUSY"

    3. Initialize() method (per D-01 lazy connect):
       - If _zkHost is null, call `ZkTecoFingerHost.Initialize()` — on non-zero return set VendorErrorCode ("ERROR_INITLIB") and return false.
       - Call `ZkTecoFingerHost.GetDeviceCount()` — if 0, retry up to 3 times with 100ms Thread.Sleep between attempts (SCAN-10 quirk: "GetDeviceCount() may return 0 after Init() on some driver versions"). After all retries, if still 0, set VendorErrorCode("ERROR_NO_DEVICE") and return false.
       - Open device via `using var deviceResult = ZkTecoFingerHost.OpenDevice(0)` — if !deviceResult.IsSuccess, set VendorErrorCode from error string, return false.
       - Cast deviceResult.Value to ZkDevice, store in _device. Query _device.Width and _device.Height for image dimensions. Set _deviceId from _device.SerialNumber ?? "ZKTeco-unknown" and _model from _device.Name ?? "ZKTeco Device". Set _isConnected = true. Return true.

    4. Scan() method:
       - If _device is null or !_isConnected, return CaptureResult.Fail("SCANNER_NOT_CONNECTED", "ZKTeco: not initialized").
       - Create CancellationTokenSource with TimeSpan.FromSeconds(5) — NOTE: actual timeout enforcement is done by ScannerManager per D-06/D-11; this 5s is a safety net inside the adapter.
       - Call `await _device.AcquireFingerprintAsync(cts.Token)` — on failure or cancellation set VendorErrorCode and return CaptureResult.Fail("CAPTURE_TIMEOUT", $"ZKTeco: capture timeout ({result.Error})") or CaptureResult.Fail("CAPTURE_FAILED", $"ZKTeco: {result.Error}").
       - On success: result.Value.Bitmap contains BMP bytes — convert to PNG via `using var bmp = new Bitmap(new MemoryStream(result.Value.Bitmap)); using var ms = new MemoryStream(); bmp.Save(ms, ImageFormat.Png); byte[] pngBytes = ms.ToArray();`.
       - Compute SHA-256 verificationData from pngBytes.
       - Return success CaptureResult with pngBytes, MimeType="image/png", Width/Height from _device properties, DeviceId, CapturedAt.

    5. Implement all IScannerAdapter members:
       - IsConnected: `get { return _isConnected && _device != null; }`
       - DeviceId: `get { return _deviceId; }`
       - Model: `get { return _model; }`
       - MimeType: `get { return "image/png"; }`
       - VendorErrorCode: `get { return _vendorErrorCode ?? "NONE"; }`
       - Dispose(): close _device if not null, call ZkTecoFingerHost.Close() if _zkHost initialized.

    6. IMPORTANT — NO pixel inversion: ZKTeco grayscale is conventional (0=white, 255=dark). Do NOT invert pixel values. Compare with SecuGenAdapter output — if displayed same orientation, the adapter is correct.

    7. Error code to string helper: `private static string ZkErrorToString(int code)` maps ZKFP_ERR_* codes to human-readable strings using the _zkErrorStrings array.
  </action>

    ## ZKTeco (ZkTecoFingerPrint NuGet + libzkfpcsharp.dll)

    ### Compatible Models
    ZK4500, ZK6500, ZK7500, ZK8500, ZK8500R, ZK9500, SLK20R, SLK20M

    The `ZkTecoFingerPrint` NuGet (MIT, v1.2.1) wraps the native DLLs and provides a sane async C# API.

    ### Setup Steps
    1. Ensure ZKFinger SDK is installed and the ZKTeco device USB driver is loaded
    2. Verify `libzkfpcsharp.dll` exists in `C:\Windows\SysWOW64\` (for 32-bit process on 64-bit OS) or `C:\Windows\System32\` (32-bit OS)

    4. Run `dotnet restore` to fetch the ZkTecoFingerPrint NuGet package

    ### Device Detection Note
    On some driver versions, `GetDeviceCount()` may return 0 immediately after `Init()`. The ZKTecoAdapter retries up to 3 times with 100ms delays before declaring no device found. If devices still not detected, try unplugging and replugging the USB cable or restarting the service.

    ### Image Format
    ZKTeco returns 8-bit conventional grayscale (0=white, 255=dark ridges). NO pixel inversion needed — this is different from Futronic which requires inversion.

    ### Timeout Behavior
    `AcquireFingerprintAsync` has no built-in timeout. The ScannerManager enforces a 10-second total budget (D-06) and ~3 seconds per adapter (D-11). If no finger is placed before the timeout, ZKTecoAdapter returns `CAPTURE_TIMEOUT`.
