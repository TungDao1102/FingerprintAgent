  <behavior>

    - ftrScanGetImageSize gets width/height for buffer allocation

    - RAW pixels INVERTED: each pixel value transformed as 255 - rawValue before PNG encoding (D-07)
    - DeviceId from ftrScanGetSerialNumber (ASCII string, null-trimmed)
    - Model hardcoded to "Futronic Scanner" or from FTRSCAN_VERSION_INFO
    - VendorErrorCode: maps error codes from research section 3 (0x200010E2 = FTR_ERROR_EMPTY_FRAME, etc.)
  </behavior>
  <action>
    Create src/FingerprintAgent/Adapters/FutronicAdapter.cs implementing IScannerAdapter:

    1. No NuGet — pure P/Invoke. Add native DLL reference note in csproj comment: place ftrScanAPI.dll in lib/Futronic/ alongside exe.

    2. Nested static class FutronicSDK with all [DllImport] declarations from research section 3. Use CallingConvention = CallingConvention.Cdecl. DLL name = "ftrScanAPI.dll". Structs: FTRSCAN_IMAGE_SIZE (int nWidth, nHeight, nImageSize), FTRSCAN_DEVICE_INFO, FTRSCAN_FRAME_PARAMETERS, FTRSCAN_VERSION_INFO, FTRSCAN_VERSION. All structs use [StructLayout(LayoutKind.Sequential, Pack = 1)].

    3. Class fields: IntPtr _device; int _imageWidth, _imageHeight; string _deviceId, _model, _vendorErrorCode; bool _isConnected.

    4. Initialize() method: _device = FutronicSDK.ftrScanOpenDevice(); if (_device == IntPtr.Zero) { _vendorErrorCode = "DEVICE_OPEN_FAILED"; return false; } FTRSCAN_IMAGE_SIZE size; if (!FutronicSDK.ftrScanGetImageSize(_device, out size)) { FutronicSDK.ftrScanCloseDevice(_device); _device = IntPtr.Zero; _vendorErrorCode = "GET_SIZE_FAILED"; return false; } _imageWidth = size.nWidth; _imageHeight = size.nHeight; // Get serial: byte[] serialBuf = new byte[32]; FutronicSDK.ftrScanGetSerialNumber(_device, serialBuf); _deviceId = Encoding.ASCII.GetString(serialBuf).TrimEnd('\0'); _model = "Futronic Scanner"; _isConnected = true; return true.

    5. Scan() method: if _device == IntPtr.Zero return CaptureResult.Fail("SCANNER_NOT_CONNECTED"); byte[] rawBuffer = new byte[_imageWidth * _imageHeight]; bool ok = FutronicSDK.ftrScanGetImage(_device, 4, rawBuffer); if (!ok) { uint err = FutronicSDK.ftrScanGetLastError(); _vendorErrorCode = MapErrorCode(err); return CaptureResult.Fail($"Futronic:{_vendorErrorCode}"); } // CRITICAL: invert pixels per D-07 byte[] inverted = new byte[rawBuffer.Length]; for (int i = 0; i < rawBuffer.Length; i++) inverted[i] = (byte)(255 - rawBuffer[i]); // Convert to PNG using BaseScannerAdapter.ToPngGrayscale or inline helper byte[] png = ToPngGrayscaleInverted(inverted, _imageWidth, _imageHeight); Compute SHA-256, return success CaptureResult.

    6. ToPngGrayscaleInverted helper: same as BaseScannerAdapter.ToPngGrayscale but skips the inversion (already inverted). Or better: reuse BaseScannerAdapter — call BaseScannerAdapter.ToPngGrayscale(inverted, width, height) since inversion is done before call.

    7. IScannerAdapter members: IsConnected (get { return _isConnected && _device != IntPtr.Zero; }), DeviceId, Model, MimeType ("image/png"), VendorErrorCode (get { return _vendorErrorCode ?? "NONE"; }).

    8. MapErrorCode helper: switch on error codes: 0x200010E2 → "FTR_ERROR_EMPTY_FRAME", 0x20000001 → "FTR_ERROR_MOVABLE_FINGER", 0x20000002 → "FTR_ERROR_NO_FRAME", 0x20000003 → "FTR_ERROR_USER_CANCELED", 0x20000004 → "FTR_ERROR_HARDWARE_INCOMPATIBLE", 0x20000005 → "FTR_ERROR_FIRMWARE_INCOMPATIBLE", 0x20000006 → "FTR_ERROR_INVALID_AUTHORIZATION_CODE". Default: $"0x{err:X}".

    9. Dispose/disconnect: add a Close() method or implement IDisposable to call ftrScanCloseDevice(_device) when the adapter is destroyed. ScannerManager will call this if needed.
