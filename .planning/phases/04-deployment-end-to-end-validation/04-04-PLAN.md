- Do NOT create a `CHANGELOG.md` file — D-26 explicit
- Do NOT bundle Playwright into the xUnit project — separate languages, separate runners
- Do NOT use Playwright 1.56+ — pinned to 1.55.1 to avoid local-network-access complications (RESEARCH.md §4)
- Do NOT use `file://` URLs for the SaaS page — modern Chrome blocks fetch from file:// to http:// (must serve from real HTTP origin)
- Do NOT add Firefox/WebKit projects to Playwright config — Chromium-only for v1, multi-browser is Phase 5+
- Do NOT auto-trigger E2E workflow on every push — D-23 manual `workflow_dispatch` only
- Do NOT add Vietnamese localization to README.md — DEPLOYMENT.md is the Vietnamese surface (D-25), README stays English
- Do NOT add emoji to README/DEPLOYMENT — project style per AGENTS.md
- Do NOT delete `docs/` until verifying no source references it — orphan refs break builds
- Do NOT skip the cleanup step in E2E workflow (uninstall MSI after tests) — leaving service installed breaks subsequent runs
- Do NOT skip the wait-for-/health loop before running Playwright tests — agent takes a few seconds to bind after install
- Do NOT add telemetry or analytics to mock backend — purely throwaway test infrastructure
- Do NOT remove any of the 5 PS1 scripts — D-32 keeps them all as dev/test fallback
