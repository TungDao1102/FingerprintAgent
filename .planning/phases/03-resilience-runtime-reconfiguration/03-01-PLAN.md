# 03-01 PLAN: Exponential Backoff + Health Check Loop

## Goal

Extend `ScannerManager` with exponential backoff (10s→30s→60s→120s) and add a background health check loop in `FingerprintAgentService` that observes `IsConnected` every 30s without probing.

## Scope

SCAN-06 — Exponential backoff with hot-plug awareness.
D-01, D-02, D-03, D-04, D-05, D-15, D-16, D-17.

## Pre-Existing Compilation Fix Applied

`CaptureResult.ErrorCode` property was missing from the class (the `Fail()` method accepted two args but never stored the error code). This has been fixed in the source. All `Fail()` calls in ScannerManager now correctly store the error code. This was a pre-existing bug surfaced by review.
